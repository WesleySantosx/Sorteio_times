#  Sorteio de Equipes

Sistema web desenvolvido para facilitar a organização e o sorteio de equipes esportivas em eventos internos de empresas.

## Objetivo

Automatizar a formação de equipes de **futebol suíço e vôlei**, distribuindo os participantes de forma aleatória, considerando suas posições e organizando os jogadores excedentes como reservas.

##  Funcionalidades

- Cadastro, edição e exclusão de participantes.
- Seleção entre futebol suíço e vôlei.
- Sorteio automático considerando as posições dos jogadores.
- Estimativa da quantidade de equipes.
- Distribuição automática de reservas.
- Visualização das equipes sorteadas.
- Armazenamento local dos participantes.

##  Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage

##  Como utilizar

1. Acesse o sistema pelo navegador.
2. Selecione a modalidade esportiva.
3. Cadastre os participantes e suas posições.
4. Configure a quantidade de jogadores por equipe.
5. Realize o sorteio e visualize os resultados.

##  Sobre o projeto

O projeto foi idealizado para solucionar uma necessidade real de organização de eventos esportivos, buscando praticidade, simplicidade e facilidade de acesso.

Desenvolvido para fins práticos e de aprendizado em Engenharia de Software.
